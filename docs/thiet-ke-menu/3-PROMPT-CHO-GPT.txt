==================== PROMPT 1 (dán từ dòng dưới) ====================
You are a senior game UI/UX artist. I am making a cozy web game called "Thị trấn AI của Hyan" (Hyan's AI Town): a hand-painted anime floating-island town seen from a fixed top-down 3/4 view, where each house is a department and chibi characters are AI agents that walk between houses, hand off tasks and wait for my approval.

Image 1 is the CURRENT game screen. Image 2 shows the current UI pieces (wood/paper panels, pill buttons, icons). I want to REDESIGN the whole menu / HUD so it feels like a polished 2D game on Steam (think Stardew Valley, Spiritfarer, Ooblets, Unpacking, Cozy Grove), clearly readable, while staying in the same soft hand-painted anime watercolor style as the town art. The town artwork itself stays exactly the same; only the UI on top changes.

UI elements that every design must include (all labels are in Vietnamese, keep them):
- Top-left title card: "Thị trấn AI của Hyan" + small green status dot + subtitle "Đội vận hành Helper"
- Toolbar with 9 buttons, each icon + label: Lướt, Tên, Bong bóng, Toàn cảnh, Tổng quan, Nhật ký, Tự chạy, Âm thanh, 1 bước duyệt (the last one is the main highlighted action)
- Right panel "Tổng quan": 4 stat counters (Đang chạy, Sắp làm, Chờ duyệt, Lỗi), a list "Chờ bạn duyệt" with cards that have Duyệt (approve) and Từ chối (reject) buttons, and a list "Bảng việc" with rows like "HLP-073  task name  [status badge]"
- Status badges: Đang chạy, Sắp làm, Chờ duyệt, Đã duyệt, Xong, Bị trả lại, Lỗi
- Bottom-left panel "Nhật ký việc": a day header and log lines "22:43  QA  text..."
- Agent detail panel (opens when clicking a character): portrait circle, name, role, current task, a progress bar, recent tasks
- A notification toast (top center) for: needs approval, error, task done
- A modal popup for important warnings/errors with 1-2 buttons
- Speech bubbles above characters and wooden name signs on houses
- A small sound settings popover: on/off toggle, 2 volume sliders, preview buttons

STEP A: First, in text only, propose 10 clearly DIFFERENT design directions for this UI kit. For each give: a short name, the material/theme (e.g. wood and parchment, stained glass, botanical garden, starry night, paper craft, ceramic tiles, cloud and sky...), color palette (5 hex colors), shape language (corners, borders, ornaments), button style, and how it keeps text readable over the busy town art.

STEP B: Then draw design #1 as ONE full-screen 16:9 mockup (1536x1024 or wider): the same town scene as image 1 in the background, with the complete redesigned UI on top showing every element listed above (toolbar, both panels, an open agent detail panel, one toast, one popup, bubbles, signs). Vietnamese text must be spelled correctly with all accents. Keep a consistent style inside each design.

After that, each time I type "tiếp", draw the next design (#2, #3 ... #10) the same way, one mockup per message. Do not repeat the same look twice.
